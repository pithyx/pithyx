# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through [GitHub security advisories](https://github.com/pithyx/pithyx/security/advisories/new). Include the affected version or commit, steps to reproduce and the impact you expect. You will get an answer as soon as possible, and we will coordinate a fix and disclosure with you.

## Supported versions

Pithyx 1.0 is marked beta. Only the latest release is supported; fixes land in the next release.
