# Pithyx

A free, self-hosted NAS and server operating system with a web desktop. Everything about installing, using, administering and developing Pithyx is in the documentation at [pithyx.org](https://pithyx.org/docs/).

## Status

Pithyx 1.0 is the first public release, and it is marked **beta**. We consider it stable, but it has not yet proven itself on real boxes in everyday use. That takes time, so until a stable release follows, treat it as beta: try it, report what breaks and keep backups of data you care about. The [changelog](CHANGELOG.md) lists the known limitations.
