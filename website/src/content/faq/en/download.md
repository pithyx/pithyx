There is no public download yet. The installer comes as one image file, `pithyx-<version>-amd64.iso`, with a `.sha256` checksum file next to it, which you write to a USB stick as a whole disk image. The image carries no signature, so the checksum only shows that the download is complete.

Details: [Write the USB stick](/docs/install/usb-stick/).
