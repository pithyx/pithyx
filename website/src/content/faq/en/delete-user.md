---
question: 'Does deleting a user delete their files?'
category: users
tags: [delete user, remove account, home folder, deactivate, files]

status: ready
---

Only if you choose so. When you delete a user, Pithyx asks what happens to their home folder: keep it (the default), move its files into a shared folder, or delete it after you typed the user name. Files the user created in shared folders always stay, and the user id is never given to anyone else. To lock someone out without deleting anything, **Deactivate** the account: it loses every right and is signed out.

Details: [Home folders](/docs/admin/home-folders/#when-a-user-is-deleted).
