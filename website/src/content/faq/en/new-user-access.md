---
question: 'Why can a new user not see a shared folder or an app?'
category: users
tags: [permissions, rights, access, grant, shared folder hidden, missing app]
order: 50
status: ready
---

A new user can sign in to the desktop, use SMB and open Files and Viewer, and nothing else. Give access to each shared folder, the other file services and the apps in the user's **Rights** dialog, or to a group the user is in. A shared folder without access is hidden, not refused.

Details: [Permissions](/docs/admin/permissions/).
