Build a static web frontend with `@pithyx/sdk`, add a `pithyx.json` manifest and an `icon.svg`, and try it with `pithyx dev`, a mock desktop on your own computer. `pithyx validate` checks it and `pithyx pack` writes the `.pithyxapp` package that an administrator installs. There is no development mode on the box.

Details: [Your first app](/docs/developers/apps/first-app/).
