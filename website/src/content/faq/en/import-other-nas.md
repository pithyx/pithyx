question: 'Can I move my existing NAS system over?'
category: install
tags: [migration, import, switch, existing nas, zfs pool]

Pithyx installs fresh only; it does not import the configuration of other systems. Existing ZFS pools can be imported in Settings > Storage after the installation, first read-only so you can check them.

Details: [Importing and exporting](/docs/admin/storage/#importing-and-exporting).
