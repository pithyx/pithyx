Open a pull request with your app's source to the community catalog `pithyx/apps-community`; the project reviews it, and CI builds, signs and publishes it. Or run your own catalog from the template `pithyx/catalog-template`, which administrators add in the Store as an unverified catalog. Every box can also install your `.pithyxapp` file directly.

Details: [Publishing to a catalog](/docs/developers/apps/publishing/).
