---
question: 'Why does the installer say "Installation in use"?'
category: install
tags: [installer, installation in use, browser, locked, second device]
order: 40
status: ready
---

The first browser that opens the installer owns the installation; every other browser sees **Installation in use**, and the console names the address that owns it. Continue in that browser. To start over, restart the computer from the stick.

Details: [Opening the installer](/docs/install/installer/#opening-the-installer).
