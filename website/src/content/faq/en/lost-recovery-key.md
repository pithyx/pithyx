---
question: 'I lost the recovery key. What now?'
category: users
tags: [recovery key, lost key, pthx, reinstall, admin password]
order: 30
status: ready
---

As long as an administrator can still sign in, nothing is lost, but the key cannot be shown again: the box stores only a hash. Using the key replaces it with a new one, and the configuration backup contains it. If you lose both the key and every administrator password, the system has to be reinstalled.

Details: [The recovery key](/docs/install/first-setup/#the-recovery-key).
