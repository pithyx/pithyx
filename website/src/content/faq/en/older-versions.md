---
question: 'Can I get an older version of a file back?'
category: files
tags: [previous versions, file history, restore points, snapshot, undo, overwritten]
order: 30
status: ready
---

Yes, if an administrator switched on restore points for the shared folder (they are on for new folders). Right-click the file in Files and choose **Previous versions**; there is one point per day for 7 days. Windows shows the same points as Previous versions over SMB.

Details: [Previous versions](/docs/user/files/#previous-versions).
