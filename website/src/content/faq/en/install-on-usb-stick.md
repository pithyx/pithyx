---
question: 'Can I install the system on a USB stick or SD card?'
category: hardware

---

Yes, if it has at least 32 GB, but the installer warns you, and you decide. The system writes logs and its database to the system disk all the time, and a cheap USB stick or memory card wears out within months. If you use one, take a USB SSD or a fast USB 3 stick of a known brand (for a card, one made for continuous use), best two as a mirror, and keep a configuration backup. Built-in eMMC, as in many small computers, counts as an internal disk and gets no warning. A hard disk works too; the installer hints that an SSD is faster, quieter and uses less power.
