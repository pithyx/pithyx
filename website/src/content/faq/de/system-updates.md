Diese Vorabversion hat auf der Box keine Update-Funktion. Eine neue Version heißt Neuinstallation: Konfigurations-Backup machen, nur auf die Systemplatten neu installieren, Pools importieren und das Backup einspielen.

Details: [Wiederherstellen und neu installieren](/de/docs/install/recovery/).
