Die API gibt Fehler als RFC-9457-Problem-Details mit stabilem `code`, `params`, englischem `detail` und der `requestId` zurück. Codes, die mit `sdk.` beginnen, kommen vom Transport des SDK im Browser, nicht vom Daemon. Diese Liste wird aus `i18n/de/errors.json` erzeugt; `{name}` steht für einen Parameter.
