Melde ein Sicherheitsproblem vertraulich über GitHub Security Advisories, nicht in einem öffentlichen Issue. Gib die betroffene Version oder den Commit an, die Schritte zum Nachstellen und die Auswirkung, die du erwartest.

## So meldest du

1. Öffne [github.com/pithyx/pithyx/security/advisories/new](https://github.com/pithyx/pithyx/security/advisories/new).
2. Beschreibe die Version oder den Commit, wie sich das Problem nachstellen lässt und was ein Angreifer tun könnte.
3. Eröffne kein öffentliches Issue und veröffentliche keine Details an anderer Stelle, bevor es einen Fix gibt.

## Was danach passiert

Das Projekt antwortet so schnell wie möglich und stimmt einen Fix und seine Veröffentlichung mit dir ab. Es gibt keine festen Reaktionszeiten und noch keine Tabelle unterstützter Versionen: Pithyx ist noch nicht veröffentlicht; das erste Release wird 1.0.0-beta.1.
