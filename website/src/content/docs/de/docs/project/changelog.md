Pithyx hat noch kein Release; das erste wird 1.0.0-beta.1, es gibt also keine veröffentlichten Versionen aufzulisten. Alle bisherigen Änderungen stehen unter „Unreleased“ in der Changelog-Datei im Repository.

## Releases

Der Changelog ist `CHANGELOG.md` im Repository: [CHANGELOG.md auf GitHub](https://github.com/pithyx/pithyx/blob/dev/CHANGELOG.md). Er folgt [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) und [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Jede Änderung, die Benutzer oder Entwickler sehen können, ergänzt eine Zeile unter „Unreleased“; bei einem Release wandern diese Zeilen unter die neue Version.

Das Produkt hat eine Versionsnummer, getaggt als `vX.Y.Z` mit einem Codenamen. Die npm-Pakete (`@pithyx/sdk`, `@pithyx/ui`, `@pithyx/cli`) haben eine eigene Versionslinie, getaggt als `sdk-vX.Y.Z`; siehe [SDK im Überblick](/de/docs/sdk/overview/#versionen-und-kanäle).
