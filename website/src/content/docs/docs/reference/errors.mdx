The API returns errors as RFC 9457 problem details with a stable `code`, `params`, an English `detail` and the `requestId`. Codes starting with `sdk.` come from the SDK's transport in the browser, not from the daemon. This list is generated from `i18n/en/errors.json`; `{name}` marks a parameter.
